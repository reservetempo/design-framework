Gute Form palettes

This page is for choosing the palette of the Gute Form framework: the calm, functional look of Braun and the Ulm School (1955 to the 1990s; Dieter Rams, “less, but better”). Each card is one candidate, with its nine colour tokens, their contrast ratios and the same sample controls drawn in it. Pick one by name; the framework is then built with it.

The colours were estimated from museum and press photos (none of these objects has an official colour spec), then adjusted so that text reaches at least 4.5:1 and lines 3:1.

added marks a colour that is not on the object itself. fill only marks a colour used only behind dark text, never as text or a line.

T 3

Braun T 3 pocket radio · Dieter Rams with the HfG Ulm · 1958

`page`, `surface`, `trim`. The T 3 is colourless; the orange and green are function colours in the Braun manner, added for UI state. A brighter signal orange (`#e2602a`) only reaches 3.54:1 with white text, so it is darkened to `#c4501a`.

Not on the object: the orange accent and the green second colour, added as Braun-style function colours for UI state.
